A simpler design workflow

Your quick guide to VELTROX Design Desk.

1. Paste the inquiry. Click New inquiry, paste the complete WhatsApp message (or upload a .txt file), check the automatic preview, and click Save inquiry. No separate field entry is required.

2. Plan the work. Set a designer, priority, and due date. Move a project from Pending to Conformation Reaming while awaiting confirmation, then to In Process when design starts.

3. Track deliverables. Tick the design checklist as work is finished. Open the project to add links to drawings and documents.

4. Complete and share. Mark the project Completed. Copy the client brief or print it to paper / PDF. Internal design notes and activity are excluded from the client brief.

Delete a project. Use the trash button in the list or Delete project in its brief. Confirm the client name before deleting. You can also archive a project to keep its history.

Project images. Select a project and use Upload images. JPG, PNG and WebP are resized to a maximum 1920 px for practical storage. Download backups include these stored images.

Closed inquiries. Select Closed and record a reason. Reopen by choosing another status. Use Urgent, High, Normal or Low priorities.

5. Back up regularly. The downloadable file stores data on this browser. The online workspace saves shared records and images in the cloud. Keep a downloaded JSON backup in either mode.

Online and offline records are separate. Use backup / restore to transfer records and photos. Merge keeps existing records on ID conflicts unless you select the newer-record option. A mobile match with a different project ID is kept and flagged for review.

Checklist progress and project status are separate, so you control when a design is complete. Site measurements and lux targets are user entries; this app does not calculate a lighting simulation.
